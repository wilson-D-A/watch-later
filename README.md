# Watch Later

Watch Later is a simple Next.js app for organizing and browsing saved videos by category, tag, and search. It provides a clean interface for filtering content and managing video metadata.

## Features

- Browse videos in a card-based layout
- Filter content by category and tags
- Search videos quickly
- Manage video tags and related actions

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- React Query

## Getting Started

1. Install dependencies:

   ```bash
   npm install
   ```

2. Start the development server:

   ```bash
   npm run dev
   ```

3. Open http://localhost:3000 in your browser.

## Available Scripts

- `npm run dev` - Start the development server
- `npm run build` - Create a production build
- `npm run start` - Start the production build
- `npm run lint` - Run ESLint

## Project Structure

- `src/pages` - Main app pages
- `src/interaction` - UI containers and page interactions
- `src/presentation` - Reusable components
- `src/hooks` - Custom hooks and logic
- `src/types` - Shared TypeScript types
